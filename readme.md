# Práctica de Git

## Explicación arquitectura monolítica y microservicios

Arquitectura monolítica: El programa se escribe en una sola unidad

Microservicios: Divide una aplicación compleja en procesos simples

## Diferencia entre frontend y backend 

Frontend: Es la capa visual que ve el cliente

Backend: En la capa lógica detrás de la aplicación
